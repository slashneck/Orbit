## Why

Shipping several apps means several download pages, several update mechanisms and
no single place a user can see what they already have. Orbit is that single
place for our catalogue: one install, and every Redrum app appears with its
version, size, patch notes and current state.

It is a launcher for our own software, not a general-purpose app store. The
catalogue is whatever our manifest lists, and nothing else.

## Features

- **Library** - every app in the catalogue with description, installed
  version and latest version.
- **App pages** - screenshots, full version history, patch
  notes, release date, download size, system requirements and install location.
- **Updates** - all inside Orbit itself. Automatically checks for updates and
  patches on users command.

## Install

Grab the latest `Orbit-Setup-<version>.exe` from
[Releases](../../releases/latest) and run it. Windows 10 64-bit or later.

The installer is unsigned, so SmartScreen will warn on first run.
